Preguntas, sugerencias o aviso de errores.

¿Has detectado una errata, un enlace desactualizado o un problema técnico en la calculadora? Escríbenos directamente por correo electrónico.

Escríbenos por correo

info@bac-calculator-us.com ↗

Este enlace abre tu gestor de correo habitual. No utilizamos formularios web para evitar la recopilación innecesaria de datos en servidores.

Qué incluir en tu mensaje

  • La dirección URL completa de la página afectada.
  • Una explicación breve del error o mejora propuesta.
  • En caso de error de cálculo: los valores numéricos introducidos para reproducirlo.
  • Para correcciones normativas: enlace a la fuente oficial correspondiente (DGT, BOE).

Por favor, no envíes datos de salud confidenciales ni expedientes sancionadores.

Este buzón no es un servicio de emergencias

No prestamos asesoramiento médico ni asistencia en recursos de multas. Si una persona presenta síntomas graves de intoxicación etílica, llama urgentemente al 112.

Privacidad de tu comunicación

Tu correo y mensaje se utilizarán exclusivamente para gestionar tu consulta. Consulta nuestra política de privacidad.

Calculadora de alcoholemia

Las estimaciones no sustituyen a un alcoholímetro ni a un análisis de sangre. Nunca conduzcas tras haber bebido.

Preguntas frecuentes

¿Ofrecéis ayuda para recurrir multas de tráfico?

No. BAC/clarity es un sitio puramente pedagógico y no ofrece asesoría legal.

¿Cómo se gestionan las correcciones técnicas?

Revisamos y contrastamos con las fuentes oficiales cualquier reporte para corregirlo a la mayor brevedad.
